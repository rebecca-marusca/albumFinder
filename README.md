
# 🎶albumFinder

albumFinder is a clean, responsive React application that allows users to search for their favorite artists and instantly discover their album discography using the official Spotify Web API. 

Built as my very first React project, this website showcases state management, asynchronous API fetching, and dynamic UI rendering with React-Bootstrap.


## 🚀Demo

https://album-finder-ten.vercel.app/

## Features

- Search for artists and browse their albums
- View album artwork and metadata
- Spotify Web API integration

## Tech Stack

* **Frontend Framework:** React (Vite)
* **Styling & UI Components:** React-Bootstrap
* **API Integration:** Spotify Web API
* **Hosting & Deployment:** Vercel


## Install

- git clone https://github.com/rebecca-marusca/albumFinder.git

- cd albumFinder

- npm install

- npm run dev

    
## Environment Variables

This project requires Spotify API credentials.

Create a .env file in the root directory:

`VITE_CLIENT_ID=your_spotify_client_id`

`VITE_CLIENT_SECRET=your_spotify_client_secret`
